<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Copy command → production-shaped tables | Command takes table names from operator argv; names interpolated into SQL |
| Correctness claim → HNSW index | The index is approximate and its build not guaranteed deterministic — trusting it corrupts the claim |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-04 | Tampering (silent corruption) | client-side vector round-trip | mitigate | Server-side INSERT..SELECT only; vectors never materialize in Python on the copy path |
| T-13-05 | Information disclosure (cross-tenant) | copy dropping owner | mitigate | Column list carries owner + created_at; owner-scoped golden queries are the gate; mutation proof required |
| T-13-06 | Denial of service (flaky truth) | HNSW inside the byte-identical claim | mitigate | Exact scan (`SET LOCAL enable_indexscan = off`) for equality; index sanity as separate set-equality check |
| T-13-07 | Injection | table names in f-string SQL | mitigate | Both --from and --to validated via PgVectorMemoryStore's constructor rule (alnum/underscore) before any SQL |
| T-13-08 | Tampering (destructive tool) | copy touching the source | mitigate | Command issues zero writes against --from; gate asserts source count unchanged after copy AND after --dry-run |
</threat_model>

      not through store.add(), whose sweep and now() stamping would make seeding
      non-deterministic.

      separate index-sanity check.
    - `recall_delta(old_results, new_results)`: per-query ordered comparison including scores;
      returns a structured delta (empty == identical).
    - `assert_tie_free(database, table, embedder)`: for every golden query, run the exact-scan
      distances unfiltered and raise if any two stored rows under the queried owner are at equal
      distance. This self-check runs in seed() callers and in the tests — it is not optional.
