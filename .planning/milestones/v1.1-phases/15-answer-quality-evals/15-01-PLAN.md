<objective>
Add the recorder seam and the fixture layer: `run_case(capture_state=True)` keeps each
turn's final AgentState instead of discarding it, and `evals/fixtures.py` turns a captured
CaseResult into a committed, validated, refusable JSON fixture.

Purpose: this is the mechanism (settled decision) by which answer quality becomes gradeable
offline — recorded answers are exactly what the pipeline said, serialized with enough
metadata to stay honest about when and on what model they were said.
Output: `evals/fixtures.py` (new), the `capture_state` seam in `evals/harness.py`, unit
tests proven against a FAKE client — no network, no keys, no spend in this plan.
</objective>

  <read_first>evals/harness.py (TurnResult/CaseResult/run_case in full), evals/graders.py (Grade), src/research_agent/graph.py lines 124-175 (AgentState + initial_state), 15-RESEARCH.md §Pattern 2 (fixture schema)</read_first>

  <action>
    Create `evals/fixtures.py` with a module docstring explaining what a fixture is (a
    recorded, known-good run: per-turn final state + metadata) and why the writer refuses
    failing recordings (a committed fixture is by construction one the judge approved —
    settled decision). Contents:

    - `FIXTURES_DIR = pathlib.Path(__file__).parent / "fixtures"` — module attribute read
      at call time (functions take `directory: Path | None = None` defaulting to the module
      attribute), so tests can monkeypatch it.
    - `SCHEMA_VERSION = 1`.
    - `class FixtureError(ValueError)` — raised on any validation failure; the loader never
      returns a partial fixture.
    - `git_sha() -> str`: `subprocess.run(["git", "rev-parse", "--short", "HEAD"], capture_output=True, text=True)`,
      stripped stdout, falling back to the sentinel `"unknown"` on empty output or OSError.
    - `build_fixture(case_id, result, *, models, recorded_at=None) -> dict`:
      takes a CaseResult produced by `run_case(..., capture_state=True)`. `models` is a
      dict of role → model-name strings with required keys exactly `"pipeline"`
      (graph.MODEL at record time) and `"judge"`; extensible — Phase 16 may add per-node
      entries (e.g. `"critic"`) without a schema bump. The schema records a MAP rather
      than a single model string deliberately: Phase 16 makes the critic model
      configurable INDEPENDENTLY of graph.MODEL (ROADMAP § Phase 16 SC-1), and the replay
      staleness gate (plan 03's fixture_current) must be able to compare whatever the
      graph exposes, today and after Phase 16 extends it. Top-level keys exactly:
      `schema_version, case_id, recorded_at` (ISO via
      `time.strftime("%Y-%m-%dT%H:%M:%S%z")`, matching run_suite's `generated_at` idiom),
      `models, git_sha, pipeline_cost_usd` (result.cost_usd rounded 6), and
      `turns`: a list of `{"label", "state", "judge"}` where `state` is the captured turn
      state dict and `judge` is `[g.as_dict() for g in turn.grades if g.judged]`. Raise
      FixtureError if any turn has `state is None` (recording without capture is a bug),
      or if `models` is missing either required key.
    - `write_fixture(fixture, result, *, force=False, directory=None) -> Path`: refuses
      (`FixtureError`) when `result.error` is set or any grade in any turn failed —
      message names the failing graders — unless `force=True`, which stamps
      `fixture["forced"] = True` before writing. Serialize `json.dumps(fixture, indent=2)`
      (readable diffs; never minified) to `<directory>/<case_id>.json`, creating the
      directory. Size guards on the encoded bytes: print a warning to stderr above 100_000
      bytes; raise FixtureError above 250_000 (a runaway draft is a bug worth seeing).
    - `load_fixture(path) -> dict`: parse JSON; validate `schema_version == SCHEMA_VERSION`,
      all required top-level keys present with correct types (str/float/list/dict) —
      `models` must be a non-empty dict of str → str containing at least `"pipeline"` and
      `"judge"` — `turns` non-empty, and every turn has `label` (str), `state` (dict),
      `judge` (list). Any violation raises FixtureError naming the path and the offending key.
    - `fixture_paths(directory=None) -> list[Path]`: sorted `*.json` under the directory,
      empty list when the directory does not exist (the pre-recording state; plan 03 keys
      replay off this).

    Tests (append to tests/test_evals.py, new section "Fixtures"):
    - `test_fixture_roundtrip`: build a fixture from a fake CaseResult whose TurnResult
      carries `state=finished()`, write it to `tmp_path`, load it back, assert the loaded
      turn state dict equals the original state dict exactly (JSON-safe by construction).
    - `test_recorder_refuses_failed_judge`: a CaseResult containing
      `Grade("judge_grounding", passed=False, detail="ungrounded", judged=True)` makes
      write_fixture raise FixtureError naming judge_grounding; with `force=True` it writes
      and the file contains `"forced": true`.
    - `test_recorder_refuses_failed_deterministic_grade` — same for a non-judge failing grade.
    - `test_a_malformed_fixture_fails_loudly`: valid JSON missing `models` (and a second
      variant with `schema_version: 2`, and a third with `models` lacking the `"pipeline"`
      key) raises FixtureError, not a partial dict.
    - `test_fixture_size_guard_rejects_a_runaway_draft`: a state with a >250 KB draft
      raises FixtureError on write.
    - `test_git_sha_falls_back_to_unknown`: monkeypatch subprocess.run to raise OSError;
      assert "unknown".
