## The register this milestone consciously left open

v1.0's README ended with nine limitations, "known, and deliberate for the scope." That
list was not debt discovered later — it was written at ship time, and it became v1.1's
entire requirements set, one requirement per limitation, all nine closed by 2026-08-11:

| v1.0 limitation (verbatim topic) | Closed by |
|---|---|
| Follow-ups can't reach for new information | Phase 17 (ADR-0011 supersedes 0003) |
| The critic shares the writer's model | Phase 16 (ADR-0010 supersedes 0005) |
| Offline evals can't measure answer quality; twelve cases are a smoke test | Phase 15 (ADR-0009) |
| Cost is computed from list prices | Phase 14 |
| Stores grow without bound; sessions have no ownership | Phase 12 |
| SQLite pins you to one machine | Phase 11 |
| No connection pool | Phase 11 |
| Changing embedding model means a new pgvector table | Phase 13 (ADR-0008) |
| The public demo is rate-limited, not authenticated | Phase 12 (ADR-0007) |

One exposure was **not** on the list because nobody knew: the unauthenticated session
routes (Phase 4's omission), found by v1.1's codebase mapping and closed as Phase 10.5.
