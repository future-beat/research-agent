# Phase 9.1: Package reorganisation (housekeeping) — Summary

> **Remastered record.** Phases 1–9 predate GSD — no CONTEXT, PLAN, or execution artifact

**Goal:** `src/` layout and one `pyproject.toml`, so a passing test run can't rely on a
module that never reaches the image.

**Shipped in:** three commits on 2026-08-02 — `3acaec7` (README restructured; design and

caught, fixed — v1.0's closing commit).

## What shipped

- **The `src/` layout** (DEC-23). The package is only importable once installed, so a
  passing test run cannot rely on a module that would never reach the image. `tests/`
  and `evals/` sit outside the package — "the eval dataset contains scripted model
  output, which has no business inside a production image."
- **One `pyproject.toml` with extras** replacing four requirements files: the base
  package is the agent alone, `[service]` adds FastAPI and the web stack, `[dev]` adds
  pytest and ruff. The image installs `[service]`, never `[dev]`. A worker that imports
  the graph never pulls in a web server.
- **The README restructure.** The whole-project story stays in `README.md`; the
  design-decision essays moved to `docs/DESIGN.md` and the runbook to
  `docs/OPERATIONS.md`. Those two documents are what v1.1's ingest classified and mined
  for DEC-01…DEC-23 — this restructure is, in hindsight, what made the GSD ingest
  possible.
- **CI caught the reorganisation's two bugs the same hour** (`5c01b3e`): a deferred
  import still pointing at the old top-level `sessions` module, and a column-0-anchored
  import rewrite. The Phase 7 investment proving its worth on its own refactor.

## Where it lives today

The layout is unchanged since: `src/research_agent/`, `tests/`, `evals/`, one
`pyproject.toml`. This commit (`5c01b3e`) is the git boundary the v1.1 milestone
measures itself from.
