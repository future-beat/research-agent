    Title: `# ADR-0001 — Routing is a deterministic Python state machine, not an LLM prompt`.
    `**Status:** Accepted`.
    `**Promoted from:** docs/DESIGN.md § The graph — "Routing is a state machine, not a
    prompt" (DEC-01)`.

    Context: an agent graph has to decide what runs next; the obvious option is to ask a
    model. Decision: `supervisor_node` is a chain of `if` statements over `AgentState`; no
    model call decides the next hop, so control flow is deterministic, unit-testable and
    identical every run — the LLM does the work, the graph decides the order. Consequences:
    the routing table is testable with no API keys and no network (this is why nothing is
    constructed at import time); the rejected alternative is an LLM router choosing the next
    node, which trades testability for flexibility the pipeline does not need. Use the word
    `deterministic` in the body.

    Do not restate the whole graph — this record covers routing only. Bounded loops (DEC-03)
    are deliberately not promoted and must not be described here as a decision of record.
