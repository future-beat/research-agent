## Non-Vacuity

**Every gate was observed red before it was trusted.** Three probes, listed in
`17.5-01-SUMMARY.md`. The one worth naming here is the third: removing a statement reds
the structural gate trivially, and only running against a server that never received the
statement shows the behavioural gate reads the catalog rather than the source. Without it,
T3 would be indistinguishable from a second copy of T1.

**The exposure was measured before the fix, not inferred.** A role holding the grants
Supabase hands `anon` read session text and identity hashes and deleted every row of
`runs`. A fix whose "before" state was never observed is a fix nobody can size.

Worth recording: **this phase's own framing was corrected mid-session.** The finding was
first reported as "confirmed live" on the strength of a `curl` returning PostgREST's 401.
That 401 is the API gateway rejecting a missing key and says nothing about whether the Data
API is enabled — it would have looked identical either way, before and after the toggle.
The finding stands on the provider's own linter output instead, and the remediation was
made independent of the setting entirely. **A probe that cannot distinguish the two states
it is being used to distinguish is not weak evidence; it is no evidence.**
