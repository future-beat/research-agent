# Phase 21.5 — Validation Strategy

> One code change (the classifier's model), one dataset resolution (labels only), one
> paid checkpoint (the re-record). The keyless suite CANNOT see the model change work —
> offline cases script the classifier — so the gates split three ways: keyless structural
> gates, the paid probe's archived evidence, and the checkpointed re-record's record.
