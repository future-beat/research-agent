<objective>
Make the judge's response boundary honest: a safety-classifier refusal becomes a graded
finding with a refusal-shaped detail, flowing into the recorder's existing failed-graders
refusal path — while malformed output keeps raising.

declined, and blaming a paid, successful pipeline run when the recorder refuses. A latent
bug on Opus 5 now, not a model-flip concern (locked decision: in scope regardless of
model).

Output: the guard, the extended fakes, and the recorder-flow proof — with every gate
observed red first.

def verdict(self, question: str) -> tuple[bool, str]:
    self.calls += 1
    response = self.client.messages.create(...)
    text = "".join(b.text for b in response.content if b.type == "text")
    try:
        parsed = json.loads(text)
        return bool(parsed["passed"]), str(parsed.get("reason", ""))
    except (json.JSONDecodeError, KeyError, TypeError) as exc:
        raise ValueError(f"Judge returned unparseable verdict: {text[:200]!r}") from exc
