<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator argv → paid API spend | The --yes gate is the only thing between an invocation and real Voyage billing |
| Preview → reality | A lying preview (wrong rate, zero-cost unknown model) is a cost surprise; DEC-12 forbids it |
| Requested dimension → table DDL | 2048 is a valid Voyage dimension but an unindexable pgvector table |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-09 | Repudiation (cost surprise) | preview | mitigate | Preview always prints tokens × verified rate; post-run reconciliation prints predicted vs actual total_tokens |
| T-13-10 | Elevation (unintended spend) | --yes gate | mitigate | Without --yes: preview prints, exit nonzero, zero embed calls; test proves no insert happened; mutation proof |
| T-13-11 | Tampering (silent coercion) | dimension handling | mitigate | Route every batch through the store's _check_dimensions (never a local copy); >2000 refused before DDL, naming halfvec as the unbuilt path |
| T-13-12 | Information disclosure (cross-tenant) | re-embed dropping owner | mitigate | Insert carries (text, embedding, owner, created_at); tenancy gate with mutation proof |
| T-13-13 | DoS (pricing gap) | unlisted model costed at $0 | mitigate | voyage_price_for raises UnknownModelPricing; command prints the error and exits nonzero — DEC-12 fail-loud |
</threat_model>
