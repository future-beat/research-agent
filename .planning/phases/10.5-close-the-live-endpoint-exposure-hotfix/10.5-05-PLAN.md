## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator shell → Fly secret store | The token crosses here once; it must never cross into a committed file |
| committed repo → deployed config | `fly.toml` `[env]` is public; secrets must not travel this way |
| deploy sequence intermediate states | Any window where new code runs without its credential is a re-exposure |
| public internet → deployed host | The only boundary that actually matters for SC-1 and SC-6 |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
