<objective>
Make the guarantee structural. SC-5 asks for a test that fails if a future endpoint is added to
the sessions group without a guard — and the obvious version of that test **passes vacuously**
on FastAPI 0.141.1, because `include_router` no longer flattens routes into `app.routes`.

Purpose: a test that iterates an empty list and goes green over a wide-open service is worse
than no test. This plan writes the recursive walker, asserts non-vacuity, and pins the DELETE's
rate limiter structurally — something no cheap behavioural test can prove, since the fixture
runs with `DEMO_RATE_LIMIT_PER_HOUR=0`.

Output: `api_routes()` and `dependency_names()` helpers plus two invariant tests, all in
`tests/test_service.py` — the module that owns the API surface. No `conftest.py`.
</objective>

    `api_routes(app)` — returns a list of `(path, route)` pairs for every `APIRoute` the app
    actually serves, including routes reached through `include_router`. Walk `app.routes`
    recursively: an `APIRoute` is collected with the accumulated prefix prepended; an
    `_IncludedRouter` is descended into via `.original_router.routes` with
    `.include_context.prefix` appended to the accumulated prefix. Import `_IncludedRouter` from
    `fastapi.routing` inside `try/except ImportError`, falling back to the empty tuple `()` so
    the `isinstance` check is simply false on a FastAPI old enough to flatten. Its docstring must
    record the reason this exists: FastAPI 0.141 stopped flattening included routers, so
    filtering `app.routes` for `APIRoute` alone finds nothing behind a router and iterates an
    empty list — which is how a guard test goes green over a wide-open service.

    `dependency_names(route)` — returns the set
    `{getattr(d.call, "__name__", "") for d in route.dependant.dependencies}`.

    Then add `test_route_guard_invariant_over_the_sessions_tree`. Name must contain
    `route_guard_invariant` so the verification contract's `-k route_guard_invariant` selector
    matches. It must:
      - Define `AUTH_DEPENDENCIES = {"guard", "require_sessions_token"}` as a module constant.
      - Collect every `(path, route)` from `api_routes(service.app)` whose path starts with
        `/sessions`.
      - **Assert non-vacuity first**: `len(routes) >= 6`, with a failure message reporting how
        many were actually found. Comment that this assertion is the point — if a future FastAPI
        changes how `include_router` stores routes, this test must fail rather than silently
        examine nothing.
      - Compute the list of `(sorted(route.methods), path)` pairs whose `dependency_names(route)`
        has an empty intersection with `AUTH_DEPENDENCIES`, and assert that list is empty. Assert
        on the list, not on a boolean, so a failure names the offending route.
      - Carry a docstring recording why the property is asserted over the route table rather than
        trusted to four decorators: the bug this phase exists to fix was four routes that each
        individually forgot one.

    This test must not use `make_client` — it inspects the app object, not a running client.
  </action>
