## Manual-Only Verifications

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| SC-6: the fix is live | REQ-live-endpoint-exposure | Requires a Fly secret and a real deploy; cannot be asserted from the test suite | 1. `fly secrets set --stage SESSIONS_TOKEN=... -a research-agent` 2. `fly deploy -a research-agent` (single cutover, also carrying Phase 10's pending commits) 3. `curl -s -o /dev/null -w "%{http_code}" https://research-agent.fly.dev/sessions` → expect 401/403 4. Repeat with the token header → expect 200 5. Confirm `/demo` still loads and a research run still completes **anonymously** |

deploy means the new code never runs without its token configured.

(`checkpoint:human-action`, blocking — needs the operator's Fly credentials).
